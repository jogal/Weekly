# ⚔️ 週間クエスト

毎日の習慣を記録してレベルアップするトラッカー。デザインはHITMANシリーズ(IOI Interactive)風のダークミニマル。

- 今日の習慣トラッカー（目標・頻度の設定、連続記録、休息日）— 下記参照
- 連続達成でゴールドが貯まり、リアルのごほうびチケット（サウナ・飲みに行く等）や護符と交換
- クエスト掲示板（「英語を累計30時間」のような積み上げ型クエスト。途切れても減らない）
- 経験値 & レベルシステム（サボると経験値がゆるやかに減衰）
- 週間 / 月間 / 年間の統計（日ごと・週ごと・月ごとのまとめ）
- PWA対応（iPhoneのホーム画面に追加して全画面・オフラインで使える）
- ⚡筋トレ記録アプリ（`gym.html`）付き — 下記参照

## ✅ 今日の習慣（週クエの「今日」タブ）

起動すると開く主画面。Grit風のカードで、その日の習慣をリング1タップで記録する。

- **目標**: チェック / 回数 / 時間（分）。頻度は 毎日 / 曜日指定 / 週N回
- **連動**: 初期習慣は筋トレ・専門医勉強・英語学習・楽器練習・自炊の5つで、XP・統計・ジムの⚡自動記録とそのまま連動する。
  筋トレは週4回が初期値で、部位を選んで記録する。独自の習慣は ＋ から追加
- **操作**: リングをタップで記録（時間の習慣は目標まで記録）、長押しで休息日。カードをタップすると細かい記録・編集・直近2週間の記録
- **さかのぼり**: 日付の列を横にスワイプするとどこまでも前の日へ戻れる（左端で4週間ずつ足される）。習慣の一覧を左右にスワイプすると1日ずつ動き、見出しの日付をタップすると日付指定でも開ける。統計のヒートマップで日を選んで「この日の記録を開く」からも行ける。ゴールドは直近7日だけ再計算するので、それより前の記録はXP・統計・クエストにだけ反映される
- **休息日**: 連続記録は途切れず、その日の達成率の分母にも入らない（XPの減衰は従来どおり）

### ゴールドとショップ

| 条件 | ゴールド |
| --- | --- |
| 目標を達成 | +10G |
| 連続2日目から1日ごと | +1G（最大 +20G） |
| 週N回の目標を達成した日 | +20G〜（連続週で最大 +50G） |
| その日の予定の習慣（2つ以上）をすべて達成 | +20G |
| 7 / 30 / 100 / 365日連続（週N回は 4 / 12 / 26 / 52週） | メダル＋50 / 200 / 700 / 3000G |

- ゴールドは記録から計算し直すので、記録を取り消すと戻る。直近7日より前は確定する
- **まもりの護符**（100G・最大3つ）: 予定の日に記録がないまま日付が変わると自動で1つ使われ、連続記録を守る。後でその日を記録すると戻る
- 称号・おとも・背景は廃止した。以前に買った分は自動で払い戻される
- 保存先は `wt_habits_v1` / `wt_habit_log_v1` / `wt_reward_v1`（追加キー。既存データは変更しない）。バックアップにも含まれる

### 日課と大きなタスク

今日タブの ＋ から「習慣」「日課」「大きなタスク」を選んで追加する。

| 種類 | 使いどころ | ゴールド |
| --- | --- | --- |
| 日課 | 歯みがき・薬など毎日の小さなこと。朝・昼・夜・いつでもで並ぶ | 1つ +2G（1日 +10Gまで）。連続記録・メダルなし |
| 大きなタスク | 論文・申告など時間のかかること。期限と小さなステップを付ける | ステップ1つ +5G、完了はタスクごとに決める（初期値 +30G） |

- 日課はタップで済み、ダブルタップで編集（長押しはスクロール中に誤作動しやすいため）。消しても過去の記録とゴールドは残る
- 日課の見出しの📅で、日課ごとの連続達成カレンダー（直近8週・週ごと）と、連続日数・最長・直近30日の達成日数を見られる（編集画面にも出る）。見るだけで、ゴールドやメダルは付かない
- 大きなタスクは習慣より上に並ぶ。期限までの日数（3日以内は黄、過ぎたら赤）とステップの進み具合を表示。期限を過ぎても減点はない
- 完了すると演出が出る。タスクをタップするとステップが下に開き、丸をタップして記録、その場でステップを追加できる。名前・アイコン・期限・ステップの並び替えは「編集」から
- 過去の日を選んでチェックすると、その日に済ませたことになる
- 保存先は `wt_todo_v1`。バックアップにも含まれる

### ごほうびチケット

ゴールドを、リアルの自分へのごほうびと交換する。ショップの「ごほうび」タブ（今日タブのゴールドを押すと開く）。

- ごほうびリストに名前・アイコン・値段を登録する。初期は「サウナに行く 700G」「飲みに行く 1000G」「買い物チケット 1500G」で、編集・削除・追加ができる
- **買う**: ゴールドでチケットと交換。値段の横に、直近7日の稼ぎから「頑張り約◯日分」の目安を出す
- **使う**: 実際にごほうびを楽しむときに押す。チケット1枚につき1回だけで、使ったチケットは戻せない
- 未使用のチケットは今日タブの🎟️と育成タブから開ける。使用済みは日付つきで残る
- ごほうびの名前や値段を変えたり消したりしても、買ったチケットはそのまま


育成タブの「クエスト掲示板」から開く（今日タブには帯を出さない。記録のたびに画面がずれるため）。

- 「筋トレを10日」「英語学習を累計30時間」「自炊を50日」のような積み上げ型のクエスト。進み具合はこれまでの記録から数えるので、休んでも減らない
- 条件を満たすと「ロック中」が「受け取る」に変わる。受け取ると次の段階（I → II → III …）が現れる
- 報酬はゴールド
- 自分で追加した習慣にも「◯◯を7日達成」から始まる専用クエストが付く
- 受け取れる報酬があると、育成タブに印が付く
- 保存するのは受け取った記録だけ（`wt_reward_v1` の `quests`）

## 📚 読書記録（本棚）

ヘッダーの **本棚**（GYMの隣）から開く、習慣とは別の読書の記録。読了した本と感想はここにずっと残る。

- 本ごとに書名・著者・全ページ数と、状態（読みたい／読書中／読了）を持つ
- **今日タブ**の「読書」に読書中の本が並ぶ。カードをタップして「何ページまで進んだか」を記録する（日付をさかのぼっても記録できる）
- **ゴールド**: 2ページ進むごとに1G（端数は次の日に持ち越し）、読了した日に全ページ数×1/4のボーナス（端数切り捨て）。習慣と同じく直近7日は記録から計算し直す
- 読了にすると残りのページまで進んだことにし、読了日と感想を残せる。読了を取り消したり読了日を変えたりすると、埋めたページとボーナスも一緒に戻る・動く
- ボーナスは1冊1回まで（確定済みなら読了し直しても付かない）。最初から読了で登録した本や、一度も記録せずに読了にした本は記録だけでゴールドなし
- **習慣「読書」**: 今日タブの習慣に「読書」が加わり、その日に1ページでも進めば達成（編集で「1日◯ページ」の目標にもできる）。連続日数・日付のリング・パーフェクトデイ・統計の達成度に入る。XPと習慣のゴールドは付かず、ゴールドはページ分だけ。リングをタップすると、読書中の本が1冊ならそのページ記録が開く
- **クエスト**: 「本の虫」（1 / 5 / 12 / 30冊読了）と「ページをめくる」（累計500 / 2000 / 6000 / 20000ページ）。XP・レベルには入らない
- **統計タブ**の下に、期間ごとの読了冊数・読んだページ・読んだ日。年間表示では月ごとの読了冊数
- 保存先は `wt_reading_v1`（追加キー）。書き出しの `readingData` に入り、これを含まない古いバックアップを復元しても今の読書記録は残る

## ⚡ 筋トレ記録（gym.html）

ズボラ向けの筋トレログ。`https://<ユーザー名>.github.io/Weekly/gym.html` で開ける（週クエのヘッダーの「⚡ ジム」ボタンからも行ける）。

- 部位タブ → 種目ボタンをタップ → 重量(±2.5/±10kg)と回数(±1)を合わせて「⚡ 記録する」を押すだけ
- 日付と時刻は自動記録。種目ごとに前回の重量・回数が自動でセットされるので、前回と同じなら⚡を押すだけ
- 数字をタップすると直接入力もできる。自重種目は重量0でOK（「自重」表示になる）
- 標準Workoutは**胸＋背中を交互に行う5種目のMain Quest**: 懸垂 → ベンチプレス → リアデルト → インクラインDBプレス → ラットプルダウン
- **5種目のうち3種目でMain Quest達成**。4種目はBonus Clear、5種目はFull Clear。疲れた日はどれかを省いてよい
- ABCDを順番に消化する必要はない。週間プランはrepeat modeでは3回を基本にし、連日より回復日を挟む配置を優先する
- 「きろく」タブから自由に種目を選んだ場合も、候補5種目のうち異なる3種目を記録すると達成扱いになる
- 旧ABCDが未編集の端末は新Main Questへ自動移行。過去ログは保持され、同一種目は可能な範囲でprogression履歴を引き継ぐ。ユーザー編集済みprogramは自動上書きしない
- 記録すると**週間クエストに自動反映**: その日のその部位の筋トレが完了扱いになり、実施時間とメモも自動で入る（経験値も入る）。セットを全部消せば取り消される
- 履歴タブで日ごとのセット・総挙上量を確認できる
- ホーム画面に追加すれば週クエとは別アイコンのアプリとして使える

### モンクと進めるGym Quest

- 起動時にモンクの2コマidle、Weeklyと同じLv/XP、今週のトレーニング回数、今日のQuestを表示。
- 5種目の行をタップすると記録欄へ移動。**3/5でMAIN QUEST CLEAR、4/5でBONUS CLEAR、5/5でFULL CLEAR**。実施順は自由で、1種目に複数セット記録しても種目数は増えません。
- 0〜2種目で終えても記録は保持。「今日は2/5。記録は残っています。」と表示します。終了時の手応え入力は任意です。
- 小さなトレーニング空間で、記録に合わせてモンクの周囲の光が変化。動きを減らす端末設定にも対応。
- 今週の冒険ルートに、Quest候補日・記録した日・予定優先日・RECOVERY DAYを表示。Google Calendarと既存のプラン生成を使用します。
- 前回重量/rep、次回目標、double progression、痛みフラグ、履歴、WeeklyへのXP反映を維持。自由記録でも痛みを指定できます。

構造・互換性・検証方法は [Gym Quest UI](docs/gym-quest-ui.md) を参照。

## 廃止した画面

音楽練習記録（`music.html`）とめぐり記録（`spots.html`）は2026-10に廃止した。古いURLやホーム画面のアイコンから開くと週クエに移る。
それまでの記録（`mus_logs`・`mus_custom`・`spot_logs`・`spot_cats`）は端末に残したままにしてあり、週クエの「設定 → データを書き出す」のファイルに `archivedData` として入る（「復元」で戻せる）。
楽器練習は週クエの今日タブで記録する。

## 🧠 Neuro Learn 連携（別アプリからの学習記録の取り込み）

学習サービス **Neuro Learn**（別リポジトリ `Neuro` の Vercel アプリ）でのその日の学習を、
週間クエストの「専門医勉強」に記録できる。

**🔄 自動同期（主経路）** — 一度設定すれば、週クエを開くだけで経験値が入っている

1. Neuro Learn のレッスン読了画面・ランダム復習の結果画面に出る「⚔️ 週間クエスト」カードで
   「🔄 自動同期を有効にする」→「🔗 接続コードをコピー」
2. 週クエの「⚙ 設定 → 🧠 Neuro Learn 自動同期」に貼って「保存して接続」（初回のみ）
3. 以後は Neuro Learn で学習すると自動でサーバーへ送られ、週クエを**開くたび／アプリに
   戻るたびに自動で取り込まれる**。その日の「専門医勉強」が完了扱いになり、
   実施時間・メモが入って XP・レベルアップ演出が出る。ヘッダーの 🧠 ボタンで手動同期もできる

前提：Neuro Learn 側の Vercel プロジェクトに **Upstash for Redis**（無料枠）を接続して
`/api/quest` の保存先を用意しておくこと（`Neuro` リポジトリの `web/README.md` 参照）。

**手動経路（サーバー未設定のときの代替）**

- Neuro Learn の「📋 記録コードをコピー」→ 週クエのヘッダー「🧠」でペースト取り込み
  （iOSのペースト許可を1回承認）
- 同じブラウザで両方を使う場合（主にデスクトップ）は `tracker.html#nl=…` の
  URLハンドオフでも取り込める

**仕組みと設計**

- 別オリジンなので localStorage は共有できない（ジム⚡の直書きとは違う）。さらに
  iPhone の**ホーム画面アプリはSafariとストレージが別**なので、URLリンクで開く方式だと
  Safari側の週クエに記録されてしまう。そのためサーバー経由の自動同期を主経路にした
- 1日分の payload は `{d:"YYYY-MM-DD", min:学習分, q:回答数, c:正解数, l:読了レッスン数}`
  （記録コードは `#nl=<base64url JSON>` に `v:1` を付けた同じ形）
- **その日の累計**が送られてくるので、何度取り込んでも記録は上書きされるだけで
  経験値の二重加算は起きない。実施時間は手入力の値と比べて大きい方を採用し、
  メモは 🧠 で始まる自動メモだけを書き換える（手書きメモは消さない）

## Vercelでデプロイする場合

1. [vercel.com](https://vercel.com/) にGitHubアカウントでログイン
2. **Add New → Project** でこのリポジトリ（`Weekly`）をImport
3. Framework Preset は **Other** のまま、何も変えずに **Deploy**（ビルド設定不要）
4. `https://<プロジェクト名>.vercel.app/` で公開される（トップは週クエ、筋トレは `/gym.html`）

以降は対象ブランチにpushするたびに自動で再デプロイされる。

> **注意**: GitHub Pages版から乗り換える場合、データ（localStorage）はドメインごとに別なので自動では引き継がれません。旧URL側の「⚙ 設定 → データを書き出す」→ 新URL側で「復元」で移行してください。

## 使い方（iPhoneで使えるようにする）

1. このリポジトリの **Settings → Pages** で「Deploy from a branch」を選び、`main` ブランチを指定して保存
2. 数分後に `https://<ユーザー名>.github.io/Weekly/tracker.html` が公開される
3. iPhoneのSafariでそのURLを開く → 共有ボタン → **「ホーム画面に追加」**
4. 以降はホーム画面のアイコンからアプリのように起動できる

> 旧環境（ローカルファイル等）で使っていたデータは、旧環境で「データ保存」→ 新環境で「復元」で移行できます。

- **アップデート**: 新しい版が公開されると、アプリに戻ったときに自動で読み込み直す（入力中やシートを開いている間は待つ）
- **ステータスバー**: 不透明の黒にしている。透過にすると、最近のiOSではホーム画面アプリの下端にステータスバーと同じ高さの描画されない帯が残り、タブバーが浮いて見えるため
- 更新しても下の帯が残る場合は、ホーム画面のアイコンを追加し直すと設定が読み直される。**アイコンを消すとアプリ内のデータも消えるので、先に「設定 → データを書き出す」で保存し、追加し直したあとに「復元」する**

## データについて

- 通常、データはすべて端末内（localStorage）に保存され、サーバーには送信されません
- 例外は **AI Coachを明示的に利用した場合のみ**: トレーニング要約・次回ターゲット・
  体重/タンパク質トレンド等の**派生情報だけ**が、自分で設定したAI endpointへ送られます
  （Googleカレンダーの生タイトルや生ログは送られません。詳細は下のAI Coach欄）
- 「データ保存」ボタンでJSONファイルとしてバックアップ、「復元」で読み込みができます
  （バックアップにAI Coachのアクセストークンは含まれません）

## 外部アプリ連携API（ディープリンク）

他のアプリから週間クエストへ成果を記録するには、次のURLを開くだけ:

```
tracker.html?quest=<カテゴリID>&min=<分>&label=<メモ>
例: tracker.html?quest=medicine&min=30&label=Neurolearn%20Ch.5
```

- カテゴリID: `medicine`(専門医勉強) / `english` / `instrument` / `cooking` / `workout_chest`等
- 今日の該当カテゴリが「完了」になり、XP獲得・レベルアップ演出が実行される
- 同じ日に複数回呼ぶと実施時間(min)が加算され、メモは連結される

NeurolearnなどからはチャプタークリアUIに上記URLへのリンク/ボタンを置けばよい。
同一オリジンで動くアプリなら、gym.html同様に `wt_records` へ直接書き込む方式も使える。

## 🤖 AI Coach（gym.html・任意機能）

ルールベースのProgressive Overload計算の結果を、AIが短い日本語で説明・補足する機能。
**未設定でもアプリは全機能動作する**（AIはoptional enhancement）。

**サーバ側（Vercel）**: このリポジトリをVercelへデプロイすると `api/coach.js` が
`POST /api/coach` として動く。環境変数をVercelのProject Settingsで設定:

| 変数 | 必須 | 説明 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | OpenAIのAPIキー（サーバのみ。ブラウザには一切出ない） |
| `OPENAI_MODEL` | - | 使用モデル（未設定時のデフォルトあり） |
| `COACH_TOKEN` | ✅(production) | 呼び出しに `Authorization: Bearer <token>` を要求。**未設定だと本番では503を返す（fail closed）**。第三者にAPIキー利用料を消費されないための必須設定。ローカル開発だけ `ALLOW_UNAUTHENTICATED_COACH=1` で明示解除可 |
| `ALLOWED_ORIGIN` | - | CORS許可オリジン（未設定は `*`）。**認証の代替にはならない** |

**アプリ側**: gym.htmlの「設定 → 🤖 AI Coach設定」でendpoint URL
（`https://<プロジェクト>.vercel.app/api/coach`）とトークン（任意）を登録。
TODAY画面のAI COACHカードから取得できる（応答は同日キャッシュ）。

送信されるのは派生情報のみ: 直近セッション要約・次回ターゲット・週間プラン・
体重/タンパク質トレンド・「水: blocked(当直/勤務ブロック)」等の定型制約。
**Googleカレンダーの生タイトルは送信しない。**
