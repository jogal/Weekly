# ⚔️ 週間クエスト

予定と成果を記録してレベルアップする、ドット絵RPG風の週間トラッカー。

- 週ごとの予定管理（リスト / カレンダー表示、ドラッグで移動）
- 成果記録（実施時間・5段階評価・メモ）
- 経験値 & レベルシステム（サボると経験値がゆるやかに減衰）
- 月間 / 年間の統計
- PWA対応（iPhoneのホーム画面に追加して全画面・オフラインで使える）
- Googleカレンダー連携（ワンタップ追加 or OAuth自動同期）

## 使い方（iPhoneで使えるようにする）

1. このリポジトリの **Settings → Pages** で「Deploy from a branch」を選び、`main` ブランチを指定して保存
2. 数分後に `https://<ユーザー名>.github.io/Weekly/tracker.html` が公開される
3. iPhoneのSafariでそのURLを開く → 共有ボタン → **「ホーム画面に追加」**
4. 以降はホーム画面のアイコンからアプリのように起動できる

> 旧環境（ローカルファイル等）で使っていたデータは、旧環境で「データ保存」→ 新環境で「復元」で移行できます。

## Googleカレンダー連携

### 方法1: ワンタップ追加（設定不要）

リスト画面の各予定にある 📅 ボタンを押すと、Googleカレンダーが予定入力済みの状態で開きます。保存を押すだけで登録完了。

### 方法2: OAuth自動同期（推奨・初回のみ設定が必要）

予定の追加・移動・削除が自動でGoogleカレンダーに反映されます。

**Google Cloud Console での設定（初回のみ、10〜15分）**

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成（名前は自由、例: `weekly-quest`）
2. **APIとサービス → ライブラリ** で「Google Calendar API」を検索して **有効化**
3. **APIとサービス → OAuth同意画面** を設定
   - User Type: **外部（External）**
   - アプリ名などを入力（自分しか使わないので適当でOK）
   - **テストユーザー** に自分のGmailアドレスを追加（これを忘れると接続できません）
4. **APIとサービス → 認証情報 → 認証情報を作成 → OAuthクライアントID**
   - アプリケーションの種類: **ウェブアプリケーション**
   - **承認済みのJavaScript生成元** に公開URLのオリジンを追加:
     - `https://<ユーザー名>.github.io`
5. 作成された **クライアントID**（`xxxx.apps.googleusercontent.com`）をコピー

**アプリ側の設定**

1. アプリ右上の **「GCal連携」** ボタンを押す
2. クライアントIDを貼り付け、「予定の追加・移動・削除を自動で同期する」にチェック
3. **「保存して接続」** を押す → Googleのログイン/許可画面が出るので許可
4. 「✅ 接続できました！」と出たら完了

以降、予定を追加するとGoogleカレンダー（メインカレンダー）に自動で登録されます。

## データについて

- データはすべて端末内（localStorage）に保存されます。サーバーには送信されません
- 「データ保存」ボタンでJSONファイルとしてバックアップ、「復元」で読み込みができます
