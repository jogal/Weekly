# ⚔️ 週間クエスト

予定と成果を記録してレベルアップする週間トラッカー。デザインはHITMANシリーズ(IOI Interactive)風のダークミニマル。

- 週ごとの予定管理（リスト / カレンダー表示、ドラッグで移動）
- 成果記録（実施時間・5段階評価・メモ）
- 経験値 & レベルシステム（サボると経験値がゆるやかに減衰）
- 月間 / 年間の統計
- PWA対応（iPhoneのホーム画面に追加して全画面・オフラインで使える）
- Googleカレンダー連携（ワンタップ追加 or OAuth自動同期）
- ⚡筋トレ記録アプリ（`gym.html`）付き — 下記参照
- 🎵音楽練習記録アプリ（`music.html`）付き — 下記参照
- 📍めぐり記録アプリ（`spots.html`）付き — 下記参照

## ⚡ 筋トレ記録（gym.html）

ズボラ向けの筋トレログ。`https://<ユーザー名>.github.io/Weekly/gym.html` で開ける（週クエのヘッダーの「⚡ ジム」ボタンからも行ける）。

- 部位タブ → 種目ボタンをタップ → 重量(±2.5/±10kg)と回数(±1)を合わせて「⚡ 記録する」を押すだけ
- 日付と時刻は自動記録。種目ごとに前回の重量・回数が自動でセットされるので、前回と同じなら⚡を押すだけ
- 数字をタップすると直接入力もできる。自重種目は重量0でOK（「自重」表示になる）
- 記録すると**週間クエストに自動反映**: その日のその部位の筋トレが完了扱いになり、実施時間とメモも自動で入る（経験値も入る）。セットを全部消せば取り消される
- 履歴タブで日ごとのセット・総挙上量を確認できる
- ホーム画面に追加すれば週クエとは別アイコンのアプリとして使える

## 🎵 音楽練習記録（music.html）

ズボラ向けの音楽練習ログ。`/music.html` で開ける（週クエ・ジムのヘッダーの「🎵」ボタンからも行ける）。

- メニュー（基礎練習・スケール・曲名など、＋で自由に追加）をタップ →「▶ タイマーで計る」を押して練習、止めると自動で分数が記録される
- タイマーを使わない場合は分数（±5/±10）を合わせて「🎵 記録する」だけ。日付と時刻は自動記録
- メニューごとに前回の分数が自動セットされる
- 記録すると**週間クエストの「楽器練習」に自動反映**: その日が完了扱いになり、合計練習時間とメモも自動で入る（経験値も入る）。記録を全部消せば取り消される
- 今週練習した曜日が♪チップで光る。履歴タブで日ごとの合計時間を確認できる
- ホーム画面に追加すれば別アイコンのアプリとして使える

## 📍 めぐり記録（spots.html）

カフェ・サウナ・クラフトビールなど「出かけた記録」用のログ。`/spots.html` で開ける（各アプリのヘッダーの「TOUR」ボタンからも行ける）。

- カテゴリ（カフェ/サウナ/ビール、＋でラーメン・銭湯など自由に追加）を選んで場所名を入れて「📍 記録する」だけ。日付と時刻は自動
- 一度行った場所はボタンになるので、**再訪はワンタップ**（訪問回数も表示される）
- ⭐評価（任意・5段階）とひとことメモ（任意）も付けられる
- スポットタブが訪問回数つきの「行きつけリスト」になっていく
- 週間クエストとは独立（紐づけ不要のゆる記録）。バックアップの書き出し/復元あり
- ホーム画面に追加すれば別アイコンのアプリとして使える

## 🧠 Neuro Learn 連携（別アプリからの学習記録の取り込み）

学習サービス **Neuro Learn**（別リポジトリ `Neuro` の Vercel アプリ）でのその日の学習を、
週間クエストの「専門医勉強」に記録できる。

**使い方（ホーム画面アプリ同士。これが主経路）**

1. Neuro Learn のレッスン読了画面・ランダム復習の結果画面に出る「⚔️ 週間クエスト」カードで
   「📋 記録コードをコピー」を押す
2. 週間クエストのアプリを開き、ヘッダーの「🧠」を押す（iOSのペースト許可を1回承認）
3. その日の「専門医勉強」が完了扱いになり、実施時間・メモが入って XP・レベルアップ演出が出る

**仕組みと設計**

- 別オリジンなので localStorage は共有できない（ジム⚡・音楽🎵の直書きとは違う）。さらに
  iPhone の**ホーム画面アプリはSafariとストレージが別**なので、URLリンクで開く方式だと
  Safari側の週クエに記録されてしまう。そのためクリップボード経由の「記録コード」を主経路にした
- コードは `#nl=<base64url JSON>`。payload は
  `{v:1, d:"YYYY-MM-DD", min:学習分, q:回答数, c:正解数, l:読了レッスン数}`
- 同じブラウザで両方を使う場合（主にデスクトップ）は、Neuro Learn 側に週クエの URL を設定すると
  `tracker.html#nl=…` を直接開くリンクも出る（起動時にハッシュを読んで同じ取り込みが走る）
- **その日の累計**が送られてくるので、何度取り込んでも記録は上書きされるだけで
  経験値の二重加算は起きない。実施時間は手入力の値と比べて大きい方を採用し、
  メモは 🧠 で始まる自動メモだけを書き換える（手書きメモは消さない）
- 予定に入れていなくても記録タブに「予定外」の行として表示される（ジムの自動記録と同じ扱い）

## Vercelでデプロイする場合

1. [vercel.com](https://vercel.com/) にGitHubアカウントでログイン
2. **Add New → Project** でこのリポジトリ（`Weekly`）をImport
3. Framework Preset は **Other** のまま、何も変えずに **Deploy**（ビルド設定不要）
4. `https://<プロジェクト名>.vercel.app/` で公開される（トップは週クエ、筋トレは `/gym.html`）

以降は対象ブランチにpushするたびに自動で再デプロイされる。

> **注意**: GitHub Pages版から乗り換える場合、データ（localStorage）はドメインごとに別なので自動では引き継がれません。旧URL側の「⚙ 設定 → データを書き出す」→ 新URL側で「復元」で移行してください。GCal連携を使っている場合は、Google Cloud Consoleの「承認済みのJavaScript生成元」に `https://<プロジェクト名>.vercel.app` の追加も必要です。

## 使い方（iPhoneで使えるようにする）

1. このリポジトリの **Settings → Pages** で「Deploy from a branch」を選び、`main` ブランチを指定して保存
2. 数分後に `https://<ユーザー名>.github.io/Weekly/tracker.html` が公開される
3. iPhoneのSafariでそのURLを開く → 共有ボタン → **「ホーム画面に追加」**
4. 以降はホーム画面のアイコンからアプリのように起動できる

> 旧環境（ローカルファイル等）で使っていたデータは、旧環境で「データ保存」→ 新環境で「復元」で移行できます。

## Googleカレンダー連携

### 方法1: ワンタップ追加（設定不要）

リスト画面の各予定にある 📅 ボタンを押すと、Googleカレンダーが予定入力済みの状態で開きます。保存を押すだけで登録完了。

### 方法2: OAuth自動同期（推奨・初回のみ設定が必要）

予定の追加・移動・削除が自動でGoogleカレンダーに反映されます。

**Google Cloud Console での設定（初回のみ、10〜15分）**

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成（名前は自由、例: `weekly-quest`）
2. **APIとサービス → ライブラリ** で「Google Calendar API」を検索して **有効化**
3. **APIとサービス → OAuth同意画面** を設定
   - User Type: **外部（External）**
   - アプリ名などを入力（自分しか使わないので適当でOK）
   - **テストユーザー** に自分のGmailアドレスを追加（これを忘れると接続できません）
4. **APIとサービス → 認証情報 → 認証情報を作成 → OAuthクライアントID**
   - アプリケーションの種類: **ウェブアプリケーション**
   - **承認済みのJavaScript生成元** に公開URLのオリジンを追加:
     - `https://<ユーザー名>.github.io`
5. 作成された **クライアントID**（`xxxx.apps.googleusercontent.com`）をコピー

**アプリ側の設定**

1. アプリ右上の **「GCal連携」** ボタンを押す
2. クライアントIDを貼り付け、「予定の追加・移動・削除を自動で同期する」にチェック
3. **「保存して接続」** を押す → Googleのログイン/許可画面が出るので許可
4. 「✅ 接続できました！」と出たら完了

以降、予定を追加するとGoogleカレンダー（メインカレンダー）に自動で登録されます。

### うまくいかないとき

- **401 / access_denied（認証段階）**: OAuth同意画面の「テストユーザー」に自分のGmailが登録されているか確認。クライアントIDの貼り付けミスも要注意（`.apps.googleusercontent.com` で終わる文字列全体）。
- **Calendar API 403（同期段階）**: ほぼ次のどちらか。
  1. **Calendar APIが未有効**: [Google Cloud Console](https://console.cloud.google.com/) → APIとサービス → ライブラリ → 「Google Calendar API」を有効化。
  2. **権限（スコープ）不足**: 専用カレンダーの作成にはカレンダー全体の権限が必要です。「GCal連携 → 保存して接続」で許可画面を再表示して承認し直してください（アプリは自動で再同意を要求します）。
  - 専用カレンダーが作れない場合でも、予定は**マイカレンダーに非公開**で登録されるようフォールバックします。

## データについて

- データはすべて端末内（localStorage）に保存されます。サーバーには送信されません
- 「データ保存」ボタンでJSONファイルとしてバックアップ、「復元」で読み込みができます
